About Base64 Encode

Base64 Encode is a free online tool that lets you encode text to Base64 and decode Base64 back to plain text. Whether you're working with API payloads, embedding images in HTML, or transmitting binary data over text-based protocols, this tool handles it all instantly in your browser.

Everything runs locally — your data never leaves your device. There are no uploads, no server processing, and no privacy concerns.

How to use

  1. Paste your text or Base64 string into the input editor on the left.
  2. Click Encode to convert plain text into Base64, or Decode to convert Base64 back to plain text.
  3. Review the output on the right. If the input is not valid Base64 when decoding, an error message will appear in the status bar.
  4. Use the Copy button to copy the result to your clipboard, or Download to save it as a file.

What is Base64?

Base64 is a binary-to-text encoding scheme that represents binary data using a set of 64 printable ASCII characters. It is commonly used to encode data that needs to be stored or transferred over media designed for text, such as embedding image data in HTML or CSS, sending email attachments via MIME, or transmitting binary data in JSON payloads for APIs.

The encoding works by mapping every 3 bytes of binary data to 4 ASCII characters, using the characters A–Z, a–z, 0–9, +, and / (with = used for padding). While Base64-encoded data is about 33% larger than the original, it is safe to use in any text-based context.

Example

Here is an example of encoding and decoding:

--- Plain Text ---
Hello, World!

--- Base64 Encoded ---
SGVsbG8sIFdvcmxkIQ==

--- Decoded Back ---
Hello, World!
