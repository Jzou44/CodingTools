用Javascript测试字符串是否符合正则表达式:

var regex_tester = /([A-Z])\w+/g;
var test_string = "This is a Test string."
console.log(regex_tester.test(test_string))

用Python测试字符串是否符合正则表达式:

import re

regex_tester = re.compile("([A-Z])\w+", re.I | re.DOTALL)
test_string = "This is a Test string."

if regex_tester.match(test_string):
    print("True")
else:
    print("False")
