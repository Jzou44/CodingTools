라우터 추적을 사용해야하는 이유는 무엇입니까?

일부 웹 사이트는 더 빠르며 다른 웹 사이트는 더 느린 것을 알아 챘습니까? 이는 일부 웹 서버가 사용자의 웹 서버에 대한 라우터가 적은 사용자에게 가까이 있기 때문에 발생합니다. 예를 들어 미국에서 중국에있는 웹 사이트를 방문하면 트래픽을 전송하는 데 10 대가 넘는 라우터가 사용됩니다. 데이터 패킷을 10 번 이상 복사하여 붙여 넣었습니다.

라우터 추적은 두 개의 IP 주소 사이의 라우터 수를 측정하고 각 라우터에 대기 시간을 추가하는 도구입니다. 또한 IPS (인터넷 서비스 공급자)의 수와 통과 한 수를 포함하여 트래픽의 전송 경로를 추적 할 수 있습니다. 국가 및 각 라우터에 할당 된 IP 주소.

전문 분야에서 라우터 추적을 사용하는 방법?

네트워크 관리에서 라우터 추적 도구를 사용하여 각 라우터에 직접 연결된 라우터와 같은 네트워크의 트리 구조를 볼 수 있습니다. 고주파수 트랜잭션에서는 속도가 모든 것입니다. 라우터 추적 도구를 사용하여 고주파수 거래 소프트웨어를 선택할 수 있습니다. 최대 속도를 얻을 수있는 위치.

Windows 시스템의 라우터 추적 (tracert): https://docs.microsoft.com/en-us/windows-server/administration/windows-commands/tracert
