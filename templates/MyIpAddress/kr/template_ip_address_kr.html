IP 주소 란 무엇입니까?

Amazon 패킷을 수신하는 데 사용하는 실제 메일 주소와 마찬가지로 IP 주소 (인터넷 프로토콜 주소)는 인터넷상의 태그 위치이므로 다른 컴퓨터 (웹 서버)는 데이터를 보낼 위치를 알고 있습니다.

인터넷 프로토콜 버전 4 (IPv4) 및 인터넷 프로토콜 버전 6 (IPv6) IPv6를 사용 : 두 개의 IP 주소가 있습니다. 128 주소를 나타내는 비트는 사용 .IPv4 IPv6를 널리 지난 10 년 동안 사용하지 않을지라도 32 (주소를 나타내는 비트를 0.0.0.0 ~ 255.255.255.255) 이는 IPv4에 총 2^32 = 4,294,967,296 독립 주소가 있음을 의미합니다 (40 억 개는 큰 숫자가 아닙니다 !!!).

사용하고있는 장치에는 고유 한 IPv4 공용 주소가 없지만 개인 IPv4 주소가 사용됩니다. 라우터에는 전용 공용 IP 주소가 있으며 모든 인터넷 트래픽을 외부 세계로 중계국으로 전송합니다.이 기술을 NAT라고합니다 네트워크 주소 변환) NAT는 공개 IPv4 주소의 소비를 줄여 줄뿐만 아니라 추가적인 보안 기능을 제공합니다.

IP 주소를 알아야하는 이유는 무엇입니까?

개인 정보 보호 정책 : 귀하의 IP 주소는 귀하의 실제 지리 정보 (국가 및 도시)를 공개 할 수 있습니다. 귀하의 인터넷 위치를 숨기기 위해 VPN 또는 프록시를 사용하는 사람들. IPS (인터넷 서비스 공급자)는 정부와 협력하는 대규모 국가 기업이지만 VPN 공급자는 고객의 개인 정보 보호를 기반으로 서비스를 제공하지만 인터넷 사용 기록을 수집하는지 확실하지 않습니다. 고급 사용자는 다른 터널을 따라가는 VPN 터널 인 Tor를 사용하여 실제 IP 주소를 알 수 없습니다.

IP 주소에 대한 추가 링크:

Wikipedia (인터넷 프로토콜): https://en.wikipedia.org/wiki/Internet_Protocol

RFC 791 (인터넷 프로토콜): https://tools.ietf.org/html/rfc791

Geolocation Query API (ip-api): http://ip-api.com/docs/

Geolocation Query API (Google지도 API): https://developers.google.com/maps/documentation/geolocation/intro

파이썬에서 IP 주소의 지리 정보 쿼리하기 (API Coding.tools 사용):

import requests
import json

ip_json_str = requests.post('https://coding.tools/my-ip-address', data={'queryIp': '8.8.8.8'}).text
ip_json = json.loads(ip_json_str)
print(ip_json)

print('IP address:', ip_json['ip'])
print('Country:', ip_json['country_name'])
print('Region:', ip_json['region_name'])
print('City:', ip_json['city_name'])
print('Latitude:', ip_json['latitude'])
print('Longitude:', ip_json['longitude'])
