Apa itu alamat IP?

Sama seperti alamat surat yang Anda gunakan untuk menerima paket Amazon, alamat IP (alamat Protokol Internet) adalah lokasi tag Anda di Internet, sehingga komputer lain (server web) tahu ke mana harus mengirim data.

Ada dua jenis alamat IP: Internet Protocol Version 4 (IPv4) dan Internet Protocol Version 6 (IPv6). IPv6 menggunakan 128 bit untuk mewakili alamat, meskipun IPv6 tidak akan banyak digunakan dalam 10 tahun terakhir. IPv4 menggunakan 32 bit untuk mewakili alamat ( 0.0.0.0 ~ 255.255.255.255). Ini berarti bahwa IPv4 memiliki total 2^32 = 4,294,967,296 alamat independen (4 miliar bukan jumlah yang besar !!!).

Perangkat yang Anda gunakan tidak memiliki alamat publik IPv4 yang unik, tetapi menggunakan alamat IPv4 pribadi. Router Anda memiliki alamat IP publik khusus dan mentransmisikan semua lalu lintas Internet ke dunia luar sebagai stasiun relay. Teknologi ini disebut NAT Terjemahan alamat jaringan). NAT tidak hanya dapat mengurangi konsumsi alamat IPv4 publik, tetapi juga memberi Anda keamanan tambahan.

Mengapa saya perlu tahu alamat IP?

Privasi. Alamat IP Anda dapat mengungkapkan informasi geografis Anda yang sebenarnya (negara mana dan kota mana) Orang yang menggunakan VPN atau proxy untuk menyembunyikan lokasi Internet Anda. Perbedaan antara keduanya adalah otoritas mana yang Anda percayai. IPS (Penyedia Layanan Internet) Anda adalah perusahaan nasional besar yang bekerja dengan pemerintah. Di sisi lain, penyedia VPN menyediakan layanan yang didasarkan pada perlindungan privasi pelanggan mereka, tetapi Anda tidak yakin apakah mereka mengumpulkan riwayat penelusuran Anda. Pengguna kelas atas merekomendasikan untuk menggunakan Tor, sebuah terowongan VPN untuk mengikuti terowongan VPN lainnya, sehingga tidak ada yang bisa mengetahui alamat IP Anda yang sebenarnya.

Permintaan geografi alamat IP dengan Python (menggunakan API Coding.tools):

import requests
import json

ip_json_str = requests.post('https://coding.tools/my-ip-address', data={'queryIp': '8.8.8.8'}).text
ip_json = json.loads(ip_json_str)
print(ip_json)

print('IP address:', ip_json['ip'])
print('Country:', ip_json['country_name'])
print('Region:', ip_json['region_name'])
print('City:', ip_json['city_name'])
print('Latitude:', ip_json['latitude'])
print('Longitude:', ip_json['longitude'])
