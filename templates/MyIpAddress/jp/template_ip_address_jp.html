IPアドレスとは

Amazonパケットを受信するために使用する実際のメーリングアドレスと同じように、IPアドレス(インターネットプロトコルアドレス)はインターネット上のタグの場所です.そのため、他のコンピューター(ウェブサーバー)がデータの送信先を認識しています.

インターネットプロトコルバージョン4(IPv4)およびインターネットプロトコルバージョン6(IPv6)のIPv6使用：2つのIPアドレスがあります. 128アドレスを表すビットは、使用.IPv4 IPv6が広く、最後の10年間に使用されていないが32 (アドレスを表すためのビットをこれは、IPv4が合計2^32 = 4,294,967,296独立したアドレスを持つことを意味します(40億は大きな数ではありません!!!).

使用しているデバイスには固有のIPv4パブリックアドレスはありませんが、プライベートIPv4アドレスを使用していますルータは専用のパブリックIPアドレスを持ち、すべてのインターネットトラフィックをリレーステーションとして外部に送信します.ネットワークアドレス変換)NATは、パブリックIPv4アドレスの消費を減らすだけでなく、セキュリティを強化することもできます.

IPアドレスを知る必要があるのはなぜですか？

プライバシー：あなたのIPアドレスはあなたの本当の地理的情報(どの国とどの市)を明らかにするかもしれませんあなたのインターネットの位置を隠すためにVPNまたはプロキシを使用する人々.あなたのIPS(インターネットサービスプロバイダ)は政府と協力する大手国営企業ですが、一方でVPNプロバイダは顧客のプライバシーを保護することに基づいてサービスを提供しますが、彼らがあなたの閲覧履歴を集めるかどうかはわかりません.ハイエンドユーザーは、他のVPNトンネルをたどるのにVPNトンネルであるTorを使用することをお勧めします.

PythonでIPアドレスの地理を問い合わせる:

import requests
import json

ip_json_str = requests.post('https://coding.tools/my-ip-address', data={'queryIp': '8.8.8.8'}).text
ip_json = json.loads(ip_json_str)
print(ip_json)

print('IP address:', ip_json['ip'])
print('Country:', ip_json['country_name'])
print('Region:', ip_json['region_name'])
print('City:', ip_json['city_name'])
print('Latitude:', ip_json['latitude'])
print('Longitude:', ip_json['longitude'])
