Was ist eine IP-Adresse?

Die IP-Adresse (Internet Protocol-Adresse) ist genau wie die tatsächliche Postadresse, die Sie zum Empfangen von Amazon-Paketen verwenden, der Ort Ihres Tags im Internet, sodass andere Computer (Webserver) wissen, wo Daten gesendet werden.

Es gibt zwei IP - Adresse: Internet Protocol Version 4 (IPv4) und Internet Protocol Version 6 (IPv6) IPv6 - Nutzung. 128 Bits , die Adresse zu repräsentieren, obwohl IPv6 weit nicht in den letzten 10 Jahren verwendeten .IPv4 verwenden 32 Bits die Adresse darstellen ( 0.0.0.0 ~ 255.255.255.255). Dies bedeutet, dass IPv4 insgesamt 2^32 = 4,294,967,296 unabhängige Adressen hat (4 Milliarden sind keine große Zahl !!!).

Das von Ihnen verwendete Gerät verfügt nicht über eine eindeutige IPv4-Adresse, sondern verwendet eine private IPv4-Adresse. Netzwerkadressenübersetzung): NAT kann nicht nur den Verbrauch öffentlicher IPv4-Adressen reduzieren, sondern bietet Ihnen zusätzliche Sicherheit.

Warum muss ich die IP-Adresse kennen?

Datenschutz: Ihre IP-Adresse zeigt möglicherweise Ihre tatsächlichen geografischen Informationen an (Land und Stadt). Personen, die Ihr Internet-Standort über VPN oder Proxy verbergen. Der Unterschied zwischen den beiden ist, welcher Behörde Sie vertrauen. Ihr IPS (Internet Service Provider) ist ein großes nationales Unternehmen, das mit der Regierung zusammenarbeitet. Andererseits bieten VPN-Anbieter Dienste an, die auf dem Schutz der Privatsphäre ihrer Kunden basieren, Sie sind sich jedoch nicht sicher, ob sie Ihren Browserverlauf erfassen. High-End-Benutzer empfehlen die Verwendung von Tor, einem VPN-Tunnel, um einem anderen VPN-Tunnel zu folgen, sodass niemand Ihre tatsächliche IP-Adresse kennen kann.

Abfrage der Geografie der IP-Adresse in Python (unter Verwendung der API Coding.tools):

import requests
import json

ip_json_str = requests.post('https://coding.tools/my-ip-address', data={'queryIp': '8.8.8.8'}).text
ip_json = json.loads(ip_json_str)
print(ip_json)

print('IP address:', ip_json['ip'])
print('Country:', ip_json['country_name'])
print('Region:', ip_json['region_name'])
print('City:', ip_json['city_name'])
print('Latitude:', ip_json['latitude'])
print('Longitude:', ip_json['longitude'])
