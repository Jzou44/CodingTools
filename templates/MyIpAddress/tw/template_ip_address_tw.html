什麼是IP地址?

就如同您用來接收亞馬遜包的真實郵寄地址,IP地址(Internet Protocol address)是標記您的標籤在互聯網上的位置,所以其他計算機(網站服務器)知道往哪裡發送數據.

有兩種IP地址: Internet協議版本4(IPv4)和Internet協議版本6(IPv6). IPv6使用128 bits來表示地址,雖然IPv6不會在近10年被廣泛使用.IPv4使用32 bits來表示地址( 0.0.0.0 ~ 255.255.255.255).這意味著IPv4一共有2^32 = 4,294,967,296個獨立的地址(40億不是一個很大的數字!!!).

您現在使用的設備沒有唯一的IPv4公共地址,但是使用了私有IPv4地址. 您的路由器有一個專用的公共IP地址,並作為一個中轉站將所有互聯網流量傳輸到外部世界. 該技術稱為NAT(網絡地址轉換). NAT不僅可以減少的公共IPv4地址的消耗,還為您提供額外的安全保障.

為什麼我要了解IP地址?

隱私. 您的IP地址可能會洩露您的真實地理信息(哪個國家/地區和哪個城市). 通常使用VPN或代理隱藏您的互聯網位置的人. 這兩者之間的差別是你信任哪個權威機構,你的IPS(互聯網服務提供商)是與政府合作的國家大公司. 另一方面,VPN提供商在保護客戶的隱私基礎上提供業務,但您不確定他們是否收集您的瀏覽歷史記錄. 對於高端用戶建議使用Tor,一個VPN隧道跟隨另一個VPN隧道. 所以沒有人能夠知道你的真實IP地址.

用Python查詢IP地址的地理(用Coding.tools提供的免費無限制API):

import requests
import json

ip_json_str = requests.post('https://coding.tools/my-ip-address', data={'queryIp': '8.8.8.8'}).text
ip_json = json.loads(ip_json_str)
print(ip_json)

print('IP address:', ip_json['ip'])
print('Country:', ip_json['country_name'])
print('Region:', ip_json['region_name'])
print('City:', ip_json['city_name'])
print('Latitude:', ip_json['latitude'])
print('Longitude:', ip_json['longitude'])
