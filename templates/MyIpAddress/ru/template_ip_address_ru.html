Что такое IP-адрес?

Так же, как реальный почтовый адрес, который вы используете для получения пакетов Amazon, IP-адрес (адрес интернет-протокола) - это местоположение вашего тега в Интернете, поэтому другие компьютеры (веб-серверы) знают, куда отправлять данные.

Существует два типа IP-адресов: Интернет-протокол версии 4 (IPv4) и Интернет-протокол версии 6. (IPv6). IPv6 использует 128 бит для представления адресов, хотя IPv6 не будет широко использоваться в последние 10 лет. IPv4 использует 32 бита для представления адресов ( 0.0.0.0 ~ 255.255.255.255). Это означает, что IPv4 имеет в общей сложности 2^32 = 4,294,967,296 независимых адресов (4 миллиарда это не большое число !!!).

Устройство, которое вы используете, не имеет уникального публичного адреса IPv4, но использует частный адрес IPv4. У вашего маршрутизатора выделенный публичный IP-адрес, и он передает весь интернет-трафик во внешний мир в качестве ретрансляционной станции. Эта технология называется NAT Трансляция сетевых адресов). NAT может не только снизить потребление общедоступных адресов IPv4, но и обеспечить дополнительную безопасность.

Зачем мне знать IP-адрес?

Конфиденциальность. Ваш IP-адрес может раскрыть вашу истинную географическую информацию (какая страна и какой город). Люди, которые используют VPN или прокси-сервер для сокрытия вашего местоположения в Интернете. Разница между ними заключается в том, какому авторитету вы доверяете. Ваш IPS (Интернет-провайдер) - крупная национальная компания, работающая с правительством. С другой стороны, провайдеры VPN предоставляют услуги, основанные на защите конфиденциальности своих клиентов, но вы не уверены, что они собирают историю посещений. Высококлассные пользователи рекомендуют использовать Tor, VPN-туннель, чтобы следовать за другим VPN-туннелем, поэтому никто не может знать ваш реальный IP-адрес.

Запрос географии IP-адреса в Python (используя API Coding.tools):

import requests
import json

ip_json_str = requests.post('https://coding.tools/my-ip-address', data={'queryIp': '8.8.8.8'}).text
ip_json = json.loads(ip_json_str)
print(ip_json)

print('IP address:', ip_json['ip'])
print('Country:', ip_json['country_name'])
print('Region:', ip_json['region_name'])
print('City:', ip_json['city_name'])
print('Latitude:', ip_json['latitude'])
print('Longitude:', ip_json['longitude'])
