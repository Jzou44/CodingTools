O que é um endereço IP?

Assim como o endereço de correspondência real que você usa para receber pacotes da Amazon, o endereço IP (endereço IP) é o local da sua tag na Internet, para que outros computadores (servidores da Web) saibam para onde enviar dados.

Há dois endereço IP: Protocolo Internet versão 4 (IPv4) e versão Internet Protocol uso 6 (IPv6) IPv6. 128 bits para representar o endereço, embora o IPv6 não é amplamente utilizado nos últimos 10 anos .IPv4 usar 32 bits para representar o endereço ( 0.0.0.0 ~ 255.255.255.255) Isto significa que o IPv4 tem um total de 2^32 = 4,294,967,296 endereços independentes (4 bilhões não é um grande número !!!).

O dispositivo que você está usando não tem um endereço público IPv4 exclusivo, mas usa um endereço IPv4 privado, seu roteador tem um endereço IP público dedicado e transmite todo o tráfego da Internet para o mundo externo como uma estação de retransmissão. Conversão de endereços de rede A NAT pode não apenas reduzir o consumo de endereços IPv4 públicos, mas também fornecer segurança adicional.

Por que preciso saber o endereço IP?

Privacidade Seu endereço IP pode revelar sua verdadeira informação geográfica (qual país e qual cidade) Pessoas que usam VPN ou proxy para esconder sua localização na Internet A diferença entre as duas é em qual autoridade você confia. O seu IPS (Internet Service Provider) é uma grande empresa nacional que trabalha com o governo, mas, por outro lado, os provedores de VPN fornecem serviços baseados na proteção da privacidade de seus clientes, mas você não tem certeza se eles coletam seu histórico de navegação. Usuários avançados recomendam o uso do Tor, um túnel VPN para seguir outro túnel VPN, para que ninguém saiba seu endereço IP real.

Consultar a geografia do endereço IP em Python (usando o API Coding.tools):

import requests
import json

ip_json_str = requests.post('https://coding.tools/my-ip-address', data={'queryIp': '8.8.8.8'}).text
ip_json = json.loads(ip_json_str)
print(ip_json)

print('IP address:', ip_json['ip'])
print('Country:', ip_json['country_name'])
print('Region:', ip_json['region_name'])
print('City:', ip_json['city_name'])
print('Latitude:', ip_json['latitude'])
print('Longitude:', ip_json['longitude'])
