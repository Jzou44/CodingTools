Qu'est-ce qu'une adresse IP?

Tout comme l'adresse postale réelle que vous utilisez pour recevoir les paquets Amazon, l'adresse IP (adresse de protocole Internet) est l'emplacement de votre balise sur Internet. Ainsi, les autres ordinateurs (serveurs Web) savent où envoyer les données.

Il existe deux types d'adresses IP: IPv4 (Internet Protocol Version 4) et IPv6 (Internet Protocol Version 6). IPv6 utilise 128 bits pour représenter les adresses, bien qu'IPv6 ne soit pas largement utilisé au cours des 10 dernières années. IPv4 utilise 32 bits pour représenter les adresses ( 0.0.0.0 ~ 255.255.255.255), ce qui signifie qu'IPv4 a un total de 2^32 = 4,294,967,296 adresses indépendantes (4 milliards n'est pas un grand nombre !!!).

Le périphérique que vous utilisez n'a pas d'adresse publique IPv4 unique, mais utilise une adresse IPv4 privée. Votre routeur dispose d'une adresse IP publique dédiée et transmet tout le trafic Internet au monde extérieur en tant que station relais. Cette technologie est appelée NAT (NAT). Traduction d'adresses réseau): le NAT peut non seulement réduire la consommation d'adresses IPv4 publiques, mais également vous apporter une sécurité supplémentaire.

Pourquoi ai-je besoin de connaître l'adresse IP?

Confidentialité. Votre adresse IP peut révéler vos véritables informations géographiques (quel pays et quelle ville). Personnes qui utilisent un VPN ou un proxy pour masquer votre emplacement Internet. La différence entre les deux est quelle autorité vous avez confiance. Votre IPS (Internet Service Provider) est une grande entreprise nationale qui collabore avec le gouvernement. Par ailleurs, les fournisseurs de VPN fournissent des services basés sur la protection de la vie privée de leurs clients, mais vous ne savez pas s'ils collectent votre historique de navigation. Les utilisateurs haut de gamme recommandent d'utiliser Tor, un tunnel VPN pour suivre un autre tunnel VPN, afin que personne ne puisse connaître votre adresse IP réelle.

Interrogez la géographie de l'adresse IP en Python (en utilisant API Coding.tools):

import requests
import json

ip_json_str = requests.post('https://coding.tools/my-ip-address', data={'queryIp': '8.8.8.8'}).text
ip_json = json.loads(ip_json_str)
print(ip_json)

print('IP address:', ip_json['ip'])
print('Country:', ip_json['country_name'])
print('Region:', ip_json['region_name'])
print('City:', ip_json['city_name'])
print('Latitude:', ip_json['latitude'])
print('Longitude:', ip_json['longitude'])
