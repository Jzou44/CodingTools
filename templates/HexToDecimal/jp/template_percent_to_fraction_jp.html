パーセント(パーセント):

パーセンテージは金融の分野で広く使用されており、パーセンテージ関数はスコアとよく似ていますが、パーセンテージは比較が簡単です.

分数:

黒い線の上の数字は分子、黒い線の下の数字は分母です分子と分母の両方は自然数ですが、それらが表す値は自然数として表現されないことがあります.

スコア変換する方法

  1. ステップ1：スコアを10の整数倍に基づく端数に変換します.

  2. ステップ2：分子と分母の最大公約数を求めます.

  3. ステップ3：分子と分母は同時に最大公約数で除算されます.

Pythonでの分数変換に対する割合:

import fractions


def percent_to_fraction(percent_number):
    decimal_number = percent_number / 100
    fraction = fractions.Fraction(decimal_number)
    return fraction


percent_input = 75
fraction_output = percent_to_fraction(percent_input)
print('fraction result is:{0}'.format(fraction_output))
