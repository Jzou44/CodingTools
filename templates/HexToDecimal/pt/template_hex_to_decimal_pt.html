Como converter de hexadecimal para decimal?

Para dígitos hexadecimais de n dígitos representados como a seguinte imagem:

dn-1dn-2...d2d1d0

Para cada dígito do número, multiplique pela potência correspondente de 16

Decimal Output = dn-1 × 16n-1 + ... + d1 × 161 + d0 × 160

Exemplo 1: convertendo o número hexadecimal "F4" em um número decimal:

Decimal Output = 15 × 161 + 4 × 160 = 244

Exemplo 2: Converta o número hexadecimal "B29E" em um número decimal:

Decimal Output = 11 × 163 + 2 × 162 + 9 × 161 + 14 × 160 = 45726

Exemplo 3: Convertendo o número hexadecimal "3.14" em um número decimal:

Decimal Output = 3 × 160 + 1 × 16-1 + 4 × 16-2 = 3.078125

Hexadecimal para conversão decimal em Python:

def hex_to_decimal(hex_str):
    decimal_number = int(hex_str, 16)
    return decimal_number


hex_input = 'ccccccccc'
decimal_output = hex_to_decimal(hex_input)
print('decimal result is:{0}'.format(decimal_output))

-------------------
decimal result is:54975581388

Conversão hexadecimal em decimal em Java:

public class NumberConvertManager {
    public static int hex_to_decimal(String hex_str) {
        return Integer.parseInt(hex_str, 16);
    }

    public static void main(String[] args) {
        String hex_input = "f4";
        int decimal_output = hex_to_decimal(hex_input);
        System.out.println("decimal result is:" + decimal_output);
    }
}

-------------------
decimal result is:244
