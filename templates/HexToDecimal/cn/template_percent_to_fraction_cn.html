百分比(Percent):

百分比代表整体的一部分(100). 百分比系统广泛用于财务中. 百分比的功能与分数非常相似,但百分比更容易比较大小.

分数(Fraction):

黑线上方的数字是分子,黑线下方的数字是分母. 虽然分子和分母都是自然数,但它自身代表的数值有时不能表示为自然数.

如何进行分数到分数转换?

  1. 步骤1: 把分数转换为以10的整数倍为底的分数.

  2. 步骤2: 找到分子和分母的最大公约数(Greatest Common Divisor).

  3. 步骤3: 分子和分母同时除以最大公约数.

用Python进行百分比到分数转换:

import fractions


def percent_to_fraction(percent_number):
    decimal_number = percent_number / 100
    fraction = fractions.Fraction(decimal_number)
    return fraction


percent_input = 75
fraction_output = percent_to_fraction(percent_input)
print('fraction result is:{0}'.format(fraction_output))
