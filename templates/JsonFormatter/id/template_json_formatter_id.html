Keunggulan JSON untuk XML:

JSON lebih mudah dibaca daripada XML, JSON menggunakan sintaksis bersih, dan membutuhkan lebih sedikit ruang.

JSON jauh lebih sederhana daripada parsing XML. JSON sangat kompatibel dengan JavaScript, dan parsing XML membutuhkan sintaks XPath yang kompleks.

Lebih banyak tautan ke JSON (Notasi Objek JavaScript):

RFC 8259 (JSON): https://tools.ietf.org/html/rfc8259

JSON dengan Python: https://docs.python.org/3/library/json.html

JSON (GSON) di Jawa: https://github.com/google/gson

Memformat string JSON dengan Python (dengan paket JSON sendiri):

import json

def format_json(str):
    resultStr = json.dumps(json.loads(str), indent=4, ensure_ascii=False)
    return resultStr

Memformat string JSON di Jawa (dengan paket GSON):

import com.google.gson.Gson;
import com.google.gson.GsonBuilder;
import com.google.gson.JsonElement;
import com.google.gson.JsonParser;

public String Format(String jsonStr){
    JsonParser parser=new JsonParser();
    JsonElement je=parser.parse(jsonStr);
    Gson gson=new GsonBuilder().setPrettyPrinting().serializeNulls().create();
    return gson.toJson(je);
}
