Essa ferramenta pode forçar a formatação de seqüências de caracteres JSON incorretas, mesmo que a cadeia de entrada não esteja de acordo com a sintaxe JSON oficial.

Vantagens do JSON para XML:

O JSON é mais fácil de ler que o XML, o JSON usa uma sintaxe mais limpa e requer menos espaço.

O JSON é muito mais simples do que o XML, o JSON é perfeitamente compatível com o JavaScript, e a análise XML requer uma sintaxe XPath complexa.

Mais links para JSON (JavaScript Object Notation):

RFC 8259 (JSON): https://tools.ietf.org/html/rfc8259

JSON em Python: https://docs.python.org/3/library/json.html

JSON (GSON) em Java: https://github.com/google/gson

Formatar strings JSON em Python (com o próprio pacote JSON):

import json

def format_json(str):
    resultStr = json.dumps(json.loads(str), indent=4, ensure_ascii=False)
    return resultStr

Formatar strings JSON em Java (com o pacote GSON):

import com.google.gson.Gson;
import com.google.gson.GsonBuilder;
import com.google.gson.JsonElement;
import com.google.gson.JsonParser;

public String Format(String jsonStr){
    JsonParser parser=new JsonParser();
    JsonElement je=parser.parse(jsonStr);
    Gson gson=new GsonBuilder().setPrettyPrinting().serializeNulls().create();
    return gson.toJson(je);
}
