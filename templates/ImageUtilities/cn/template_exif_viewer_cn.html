什么是Exif?

在苹果IOS系统相册中, 所有图片按地理位置和拍摄时间自动整理, 苹果是如何获得照片的地理位置和拍摄时间信息? 这是因为照片文件不仅仅包含像素和颜色, 还包含GPS定位等信息.

本站图片缓存:

所有上传的图片会在1小时后删除, 请尽快下载生成的结果文件. 请不要把本网站当作图片存储服务器.

用python从照片中提取EXIF信息 (用 exifread):

import exifread

origin_file_path = './origin.jpg'

with open(origin_file_path, "rb") as image_file:
    tags = exifread.process_file(image_file)

for key in tags.keys():
    value = str(tags[key])
    print('{0}:{1}'.format(key, value))
