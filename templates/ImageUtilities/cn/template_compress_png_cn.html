PNG格式图片为什么能支持透明背景?

JPEG格式图片用RGB颜色表示每个像素, PNG格式图片用RGBA颜色表示每个像素. 'A'代表 透明的, 当背景的透明度为 0%时, 背景显示为透明.

PNG vs JPEG 图片格式对比:

对比内容 PNG JPEG
压缩级别 无损压缩 有损压缩
EXIF 不支持EXIF 支持EXIF
透明 支持透明 不支持透明
用途 生成图像 照片

本站图片缓存:

所有上传的图片会在1小时后删除, 请尽快下载生成的结果文件. 请不要把本网站当作图片存储服务器.

用Python压缩PNG (用Pillow):

from PIL import Image # pip3 install pillow

origin_file_path = './origin.png'
compressed_file_path = './compressed.png'

original_image = Image.open(origin_file_path)
original_image.convert('P')
original_image.save(compressed_file_path, optimize=True, quality=80)
