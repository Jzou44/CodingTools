Le codage Base64 peut-il chiffrer mes données?

Impossible. Base64 ne peut que changer l'apparence de la chaîne, aucun mot de passe n'est requis pour décoder la chaîne Base64.

Plus de liens vers Base64:

RFC 3548: https://tools.ietf.org/html/rfc3548.html

Base64 en Python: https://docs.python.org/2/library/base64.html

Base64 en Java: https://docs.oracle.com/javase/8/docs/api/java/util/Base64.html

Chaînes de codage Base64 en Python (avec le package base64):

import base64

def base64_encode(str):
    return base64.b64encode(str.encode())

Base64 avec chaînes codées en Java (avec le package MessageDigest):

import java.util.Base64;

public String encode(String str)  {
    byte[] encodedBytes = Base64.getEncode().encode(str.getBytes());
    String text = new String(encodedBytes);
    return text;
}
