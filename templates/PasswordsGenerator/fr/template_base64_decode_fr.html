Décoder la chaîne Base64 en Python (avec le package base64):

import base64

def base64_decoder(str):
    return base64.b64decode(str.encode())

Base64 pour le décodage de chaînes en Java (avec le package MessageDigest):

import java.util.Base64;

public String decode(String str)  {
    byte[] decodedBytes = Base64.getDecoder().decode(str.getBytes());
    String text = new String(decodedBytes);
    return text;
}
