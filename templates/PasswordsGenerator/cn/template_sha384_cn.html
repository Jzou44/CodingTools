SHA384简介:

SHA-384与SHA-512算法非常相似. 不同的是SHA-384仅产生384位长度的结果,因此SHA-384并不像SHA-512那样安全.

{%include "Common/Ad_PlaceHolder/seg_ad_left_cartoon.html" %}

更多关于SHA384的链接:

RFC 4634: https://tools.ietf.org/html/rfc4634

Python中的SHA384 (hashlib): https://docs.python.org/3/library/hashlib.html

Java中的SHA384: https://docs.oracle.com/javase/7/docs/api/java/security/MessageDigest.html

用Python计算字符串的SHA384哈希值 (用 package hashlib):

import hashlib

def sha384_generator(str):
    m = hashlib.sha384()
    m.update(str.encode())
    return m.hexdigest()

用Java计算字符串的SHA384哈希值 (用 package MessageDigest):

import java.math.BigInteger;
import java.security.MessageDigest;

public String generate(String str){
    MessageDigest md = MessageDigest.getInstance("SHA-384");
    md.update(str.getBytes());
    byte[] digest = md.digest();
    String result = new BigInteger(1, digest).toString(16).toUpperCase();
    return result;
}

在Linux中计算文件的SHA384哈希值 (用 OpenSSL):
