SHA384の紹介:

SHA-384はSHA-512アルゴリズムと非常によく似ていますが、違いはSHA-384は384ビット長の結果しか生成しないため、SHA-384はSHA-512ほど安全ではありません.

SHA384へのより多くのリンク:

RFC 4634: https://tools.ietf.org/html/rfc4634

PythonでのSHA384(hashlib): https://docs.python.org/3/library/hashlib.html

JavaでのSHA384: https://docs.oracle.com/javase/7/docs/api/java/security/MessageDigest.html

Pythonで文字列のSHA384ハッシュを計算する(hashlibパッケージ付き):

import hashlib

def sha384_generator(str):
    m = hashlib.sha384()
    m.update(str.encode())
    return m.hexdigest()

Javaで文字列のSHA384ハッシュを計算する(MessageDigestパッケージを使って):

import java.math.BigInteger;
import java.security.MessageDigest;

public String generate(String str){
    MessageDigest md = MessageDigest.getInstance("SHA-384");
    md.update(str.getBytes());
    byte[] digest = md.digest();
    String result = new BigInteger(1, digest).toString(16).toUpperCase();
    return result;
}
