SHA512에 대한 추가 링크:

RFC 4634: https://tools.ietf.org/html/rfc4634

파이썬에서 SHA512 (hashlib): https://docs.python.org/3/library/hashlib.html

자바로 된 SHA512: https://docs.oracle.com/javase/7/docs/api/java/security/MessageDigest.html

PHP의 SHA512: http://php.net/manual/en/function.hash.php

Python에서 문자열의 SHA512 해시 계산 (패키지 hashlib 사용):

import hashlib

def sha512_generator(str):
    m = hashlib.sha512()
    m.update(str.encode())
    return m.hexdigest()

Java에서 문자열의 SHA512 해시 계산 (MessageDigest 패키지 사용):

import java.math.BigInteger;
import java.security.MessageDigest;

public String generate(String str){
    MessageDigest md = MessageDigest.getInstance("SHA-512");
    md.update(str.getBytes());
    byte[] digest = md.digest();
    String result = new BigInteger(1, digest).toString(16).toUpperCase();
    return result;
}
