Bisakah base64 mengenkripsi data saya?

Tidak dapat. Base64 hanya dapat mengubah tampilan string, tidak ada kata sandi yang diperlukan untuk mendekode string Base64.

Lebih banyak tautan ke Base64:

RFC 3548: https://tools.ietf.org/html/rfc3548.html

Base64 dengan Python: https://docs.python.org/2/library/base64.html

Base64 di Jawa: https://docs.oracle.com/javase/8/docs/api/java/util/Base64.html

String pengkodean Base64 dengan Python (dengan paket base64):

import base64

def base64_encode(str):
    return base64.b64encode(str.encode())

Base64 dengan string Java encoded (dengan paket MessageDigest):

import java.util.Base64;

public String encode(String str)  {
    byte[] encodedBytes = Base64.getEncode().encode(str.getBytes());
    String text = new String(encodedBytes);
    return text;
}
