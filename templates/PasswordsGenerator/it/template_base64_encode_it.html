La codifica Base64 può crittografare i miei dati?

Impossibile. Base64 può solo modificare l'aspetto della stringa, non è richiesta alcuna password per decodificare la stringa Base64.

Altri collegamenti a Base64:

RFC 3548: https://tools.ietf.org/html/rfc3548.html

Base64 in Python: https://docs.python.org/2/library/base64.html

Base64 in Java: https://docs.oracle.com/javase/8/docs/api/java/util/Base64.html

Stringhe di codifica Base64 in Python (con pacchetto base64):

import base64

def base64_encode(str):
    return base64.b64encode(str.encode())

Base64 con stringhe codificate Java (con pacchetto MessageDigest):

import java.util.Base64;

public String encode(String str)  {
    byte[] encodedBytes = Base64.getEncode().encode(str.getBytes());
    String text = new String(encodedBytes);
    return text;
}
