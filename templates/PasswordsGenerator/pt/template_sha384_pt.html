Introdução ao SHA384:

O SHA-384 é muito semelhante ao algoritmo SHA-512. A diferença é que o SHA-384 produz apenas resultados de comprimento de 384 bits, portanto, o SHA-384 não é tão seguro quanto o SHA-512.

Mais links para SHA384:

RFC 4634: https://tools.ietf.org/html/rfc4634

SHA384 em Python (hashlib): https://docs.python.org/3/library/hashlib.html

SHA384 em Java: https://docs.oracle.com/javase/7/docs/api/java/security/MessageDigest.html

Calcular o hash SHA384 de uma string em Python (com hashlib de pacote):

import hashlib

def sha384_generator(str):
    m = hashlib.sha384()
    m.update(str.encode())
    return m.hexdigest()

Calcular o hash SHA384 de uma string em Java (com o pacote MessageDigest):

import java.math.BigInteger;
import java.security.MessageDigest;

public String generate(String str){
    MessageDigest md = MessageDigest.getInstance("SHA-384");
    md.update(str.getBytes());
    byte[] digest = md.digest();
    String result = new BigInteger(1, digest).toString(16).toUpperCase();
    return result;
}
