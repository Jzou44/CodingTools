SOBRE SHA224:

O SHA-224 também é conhecido como "message digest". O SHA-224 é projetado pelo Instituto Nacional de Padrões e Tecnologia (NIST) e é um algoritmo hash baseado no SHA-256.

Mais links para SHA224:

RFC 4634: https://tools.ietf.org/html/rfc4634

SHA224 (hashlib) em Python: https://docs.python.org/3/library/hashlib.html

SHA224 em Java: https://docs.oracle.com/javase/7/docs/api/java/security/MessageDigest.html

Calcular o hash SHA224 de uma string em Python (com hashlib de pacote):

import hashlib

def sha224_generator(str):
    m = hashlib.sha224()
    m.update(str.encode())
    return m.hexdigest()

Calcular o hash SHA224 de uma string em Java (com o pacote MessageDigest):

import java.math.BigInteger;
import java.security.MessageDigest;

public String generate(String str){
    MessageDigest md = MessageDigest.getInstance("SHA-224");
    md.update(str.getBytes());
    byte[] digest = md.digest();
    String result = new BigInteger(1, digest).toString(16).toUpperCase();
    return result;
}

Calcular o hash SHA224 de um arquivo no Linux (com OpenSSL):

root@instance-4:/var/log/apache2# openssl dgst -sha224 access.log
