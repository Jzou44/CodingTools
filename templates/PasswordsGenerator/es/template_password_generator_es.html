6 consejos sobre seguridad de contraseña:

  • 1. Para su seguridad, todo el tráfico de Internet en este sitio web se realiza bajo el protocolo https .

  • 2. No use la misma contraseña en diferentes sitios web. Si un sitio web está comprometido, se revelará la identidad de otros sitios web.

  • 5. No utilice contraseñas simples como '123456' o 'abcdefg' porque son fáciles de adivinar.
