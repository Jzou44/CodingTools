¿Puede la codificación Base64 cifrar mis datos?

Can't .Base64 solo puede cambiar el aspecto de la cadena, no se requiere contraseña para descodificar la cadena Base64.

Más enlaces a Base64:

RFC 3548: https://tools.ietf.org/html/rfc3548.html

Base64 en Python: https://docs.python.org/2/library/base64.html

Base64 en Java: https://docs.oracle.com/javase/8/docs/api/java/util/Base64.html

Cadenas de codificación Base64 en Python (con el paquete base64):

import base64

def base64_encode(str):
    return base64.b64encode(str.encode())

Base64 con cadenas codificadas Java (con el paquete MessageDigest):

import java.util.Base64;

public String encode(String str)  {
    byte[] encodedBytes = Base64.getEncode().encode(str.getBytes());
    String text = new String(encodedBytes);
    return text;
}
