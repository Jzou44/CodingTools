Más enlaces a Base64:

RFC 3548: https://tools.ietf.org/html/rfc3548.html

Base64 en Python: https://docs.python.org/2/library/base64.html

Base64 en Java: https://docs.oracle.com/javase/8/docs/api/java/util/Base64.html

Decodifica la cadena Base64 en Python (con el paquete base64):

import base64

def base64_decoder(str):
    return base64.b64decode(str.encode())

Base64 para decodificar cadenas en Java (con el paquete MessageDigest):

import java.util.Base64;

public String decode(String str)  {
    byte[] decodedBytes = Base64.getDecoder().decode(str.getBytes());
    String text = new String(decodedBytes);
    return text;
}
