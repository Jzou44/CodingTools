هل يمكن تشفير Base64 تشفير بياناتي؟

لا يمكن .Base64 تغيير مظهر السلسلة فقط ، لا يلزم كلمة مرور لفك سلسلة Base64.

المزيد من الروابط إلى Base64:

RFC 3548: https://tools.ietf.org/html/rfc3548.html

Base64 في بايثون: https://docs.python.org/2/library/base64.html

Base64 في جاوة: https://docs.oracle.com/javase/8/docs/api/java/util/Base64.html

سلاسل التشفير Base64 في Python (مع حزمة base64):

import base64

def base64_encode(str):
    return base64.b64encode(str.encode())

Base64 مع ترميز Java سلاسل (مع حزمة MessageDigest):

import java.util.Base64;

public String encode(String str)  {
    byte[] encodedBytes = Base64.getEncode().encode(str.getBytes());
    String text = new String(encodedBytes);
    return text;
}
