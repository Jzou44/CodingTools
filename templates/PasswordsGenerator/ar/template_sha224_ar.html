حول SHA224:

يعرف SHA-224 أيضًا باسم "message digest" ، وقد تم تصميم SHA-224 بواسطة المعهد الوطني للمعايير والتقنية (NIST) ، وهو عبارة عن خوارزمية هاش تستند إلى 256 SHA.

المزيد من الروابط إلى SHA224:

RFC 4634: https://tools.ietf.org/html/rfc4634

SHA224 (hashlib) في بايثون: https://docs.python.org/3/library/hashlib.html

SHA224 في جاوة: https://docs.oracle.com/javase/7/docs/api/java/security/MessageDigest.html

حساب تجزئة SHA224 لسلسلة في Python (مع حزمة hashlib):

import hashlib

def sha224_generator(str):
    m = hashlib.sha224()
    m.update(str.encode())
    return m.hexdigest()

حساب تجزئة SHA224 لسلسلة في Java (مع وجود MessageDigest):

import java.math.BigInteger;
import java.security.MessageDigest;

public String generate(String str){
    MessageDigest md = MessageDigest.getInstance("SHA-224");
    md.update(str.getBytes());
    byte[] digest = md.digest();
    String result = new BigInteger(1, digest).toString(16).toUpperCase();
    return result;
}

احسب تجزئة SHA224 في ملف في Linux (مع OpenSSL):
